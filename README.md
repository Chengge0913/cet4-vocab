# 词屿 · CET-4 刷词工作台

为 iPhone 竖屏设计的离线四级词汇练习 PWA。应用使用 HTML5、预编译 Tailwind CSS 和原生 JavaScript，所有学习进度均写入当前设备的 localStorage。

## 运行与安装

将 `dist/` 的完整内容放在同一个 HTTPS 静态网站目录即可运行，也支持部署在子路径。本地预览可以在仓库根目录执行：

```sh
python3 -m http.server 8000 --directory dist
```

在浏览器打开 `http://localhost:8000`。首次联网打开后，等待右上角显示「离线就绪」。在 iPhone 上从 Safari 的分享菜单选择「添加到主屏幕」，可在飞行模式下重新打开并练习。首次缓存需要 HTTPS 或 localhost；从手机访问局域网 HTTP 地址无法安装 Service Worker。

## 出题规则

- 常规练习按顺序学习新词。切换模式会立即重新抽题并排除上一个词；抽中未学库时，随机选一个未学词。切换不计入答题次数、正确率或连胜。四个选项词性一致，干扰项优先匹配相同主题。
- 常规题位使用同一个随机数抽签：15% 抽查已掌握词、35% 抽查高频错题、50% 学新词。选中的库没有可用词时优先补入新词；新词耗尽后按可用复习库分配。
- 每次答错都会清空该词连胜，并在其后的第 3～6 题中随机预留一个未占用题位。预留题位优先，期间该词不参与随机抽取。因此实际总出题比例会随错答频率和各库是否为空而变化。
- 新词答对即掌握。错题连续答对三次后晋级，已掌握词答错立即降级。
- 当前题、选项顺序、答题反馈和预留题位都会随进度保存。设置支持 JSON 备份、校验并恢复备份、重置记录。

## 词库和发音

800 个词条位于 `dist/words.js`，包含美音音标、词性、核心义、干扰项主题、真题摘录、译文及原卷出处。241 处双语摘录来自 70 套四级试卷，每条标明考次和卷别。词表是根据真题整理的练习选集，不代表官方频率排名。

美音音标的数据来源、署名与许可见 [词库资料说明](dist/assets/word-data-notices.txt)。

[历年 CET-4 原卷](https://github.com/Longtaao/CET-Past-Papers/tree/17fb70de7f4b79a2d514d7650bf119ce227cafbc/CET-4)

第一次用户交互会初始化 Web Speech 和 Web Audio，优先使用系统美音语音。缺少美音、语音服务报错或未启动时，应用使用已缓存的 Flite SLT 美音音频，播报无需联网。iOS 首次进入页面时需要一次用户手势。新增词汇的离线录音按每 50 词分包，播放时仅解码当前所需的音频包。

答题音效使用 Web Audio 振荡器实时合成，答对为上行双音，答错为低音短鸣。「设置 → 答题音效」可独立于朗读开关调整。升级应用或导入旧备份时默认开启音效，原有学习记录继续保留。

应用更新会先缓存完整的新版本。已打开旧版的用户可在联网时打开一次应用，关闭全部该应用页面后重新进入，以启用更新。

## 验证

```sh
node --test tests/*.test.cjs
```

测试覆盖 800 个词的题组、切换模式后的换词、旧备份恢复、抽查权重边界、连续错误的回访时限、晋降级、备份校验和离线资源清单。修改静态资源时请同时更新 `dist/service-worker.js` 的缓存版本，新增文件应加入预缓存清单。
